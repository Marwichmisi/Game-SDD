# GDScript first, C# en variante

La cible est Godot 4.x 2D+3D sans bridage, donc tout le socle, les exemples et les seams de test sont GDScript first : le chemin par défaut n'impose ni build .NET ni patterns C#.

> **Révisé après la curation (#10).** Ce texte disait initialement que « le skill godot-csharp reste disponible sur demande explicite ». La curation a écarté ce skill : la variante C# reste *supportée* (build mono, API Godot C#), mais elle passe par la documentation de l'API Godot et non par un skill de la Couche jeu, réimportable explicitement depuis l'upstream. La décision de fond — GDScript first — ne change pas.
