# Étiquettes de triage

Les skills utilisent cinq rôles de triage canoniques. Ce fichier associe chaque rôle à l’étiquette réellement utilisée dans GitHub Issues.

| Rôle canonique                | Étiquette GitHub     | Signification                                      |
| ----------------------------- | -------------------- | -------------------------------------------------- |
| `needs-triage`                | `needs-triage`       | Le ticket doit être évalué par un mainteneur      |
| `needs-info`                  | `needs-info`         | Le rapporteur doit fournir davantage d’informations |
| `ready-for-agent`             | `ready-for-agent`    | Le ticket est entièrement spécifié et prêt pour un agent |
| `ready-for-human`             | `ready-for-human`    | Le ticket nécessite une intervention humaine      |
| `wontfix`                     | `wontfix`            | Le ticket ne sera pas traité                       |

Lorsqu’un skill mentionne un rôle, utiliser la chaîne d’étiquette correspondante dans ce tableau.
